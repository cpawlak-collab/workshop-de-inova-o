# workshop-de-inova-o
Aplicação web em HTML5, CSS3 e Chart.js para gestão orçamentária e operacional (total de R$ 58.500,00). Conta com 6 gráficos interativos (rosca, barras agrupadas, linha de área, radar, misto e área polar) para analisar custos, metas de inscrição, satisfação e alocação de equipe.
